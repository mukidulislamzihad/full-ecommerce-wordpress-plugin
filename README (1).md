# Full Ecommerce WordPress Plugin

A collection of custom WordPress plugins for e-commerce stores. Each plugin adds a specific feature or design element — just activate it and (where applicable) drop in the shortcode on any page or post.

---

## How to Use

1. Download the plugin you need from the tables below (zip file)
2. WordPress Admin → **Plugins** → **Add New** → **Upload Plugin** → select the zip file and upload
3. Click **Activate**
4. If the plugin uses a shortcode, go to the page/post where you want it and paste the shortcode
5. Save/Update — done
